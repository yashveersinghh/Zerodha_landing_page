Welcome to the **Zerodha Landing Page Clone**, a front-end project built purely with **HTML** and **CSS**.  
This project was created as a learning exercise to practice modern layout techniques and design replication.

## 🧠 Project Overview

This is a **static clone** of the [Zerodha](https://zerodha.com) homepage, built for educational purposes.  
The goal was to **closely mimic the structure and styling** of the original site while improving skills in:

- Responsive layout fundamentals
- Clean and semantic HTML structure
- CSS styling with a focus on visual accuracy

> ⚠️ Note: This is a **front-end only** project with no backend functionality.

---

- CSS3
